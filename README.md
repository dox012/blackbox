# blackbox

一个常驻系统托盘的 Windows 小工具：一键把**所有显示器**盖成全黑、隐藏鼠标、并阻止系统休眠/息屏——屏幕实际仍常亮、电脑后台照常运行。配合给显示器电源指示灯贴一小块黑胶带，即可伪装成待机状态。

- 单文件、约 15 KB、**零依赖**（使用 Windows 自带 .NET Framework）
- 不安装、不写注册表、不自启、不联网，删掉 exe 即彻底清除
- 支持定时/常亮、实时遮挡程序弹窗（见下）

## 使用

| 操作 | 方法 |
|------|------|
| 启动常驻 | 双击 `blackbox.exe`，右下角出现黑色小方块图标 |
| 开 / 关黑屏 | **左键单击**托盘图标（或右键 → "黑屏"） |
| 收回黑屏 | 黑屏时按 **`Esc`**（程序仍在托盘待命，可随时再开） |
| 定时黑屏 / 常亮 | 右键 → "定时黑屏…" → 输入分钟数 |
| 彻底退出 | 右键托盘图标 → "退出" |

> 黑屏期间鼠标键盘照常工作，仅画面全黑、指针隐藏；退出后系统休眠设置自动还原。

### 定时黑屏 / 常亮

"定时黑屏"用本程序的计时**接管系统的休眠 / 息屏**，按空闲时间触发：

- **正数 N 分钟**：键鼠空闲满 N 分钟后自动盖黑（像息屏 / 屏保），期间阻止系统抢先休眠；有任意操作即重新计时，按 `Esc` 收回后也重新计时。
- **负数（常亮）**：永久阻止系统休眠 / 息屏，永不自动黑屏。
- **0（关闭）**：交还系统自身的休眠设置，默认即此项。

> 该设置仅存于内存，**重启程序后恢复为"关闭"**——保持"不写注册表、不留痕、删 exe 即彻底清除"的特性。

## 自行编译

源码仅一个文件 `blackbox.cs`，用 Windows 自带的 C# 编译器即可生成 exe：

```bash
csc.exe /target:winexe /out:blackbox.exe \
        /win32icon:blackbox.ico \
        /reference:System.dll \
        /reference:System.Windows.Forms.dll \
        /reference:System.Drawing.dll \
        blackbox.cs
```

编译器路径通常为 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`。

## 说明

- 因 exe 无数字签名，首次运行可能被 SmartScreen 或安全软件提示，点"仍要运行"或加入信任即可——源码公开、无任何危险操作。
- 黑屏期间实时监听窗口事件（弹窗一出现就在几十毫秒内把黑屏抬回最前），可盖住微信 / QQ / 钉钉等**程序自身**的置顶弹窗，几乎无闪现。但 Windows **系统通知（toast）** 由系统进程绘制在更高的窗口层级，普通程序无法遮挡——若需彻底不被打扰，请手动开启系统的"专注助手 / 勿扰模式"。
- 仅支持 Windows，不支持 macOS / Linux。
